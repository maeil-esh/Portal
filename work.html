📄 현황 엑셀 수정 방법
1
선택 사업장 현황 엑셀 다운로드

아래 버튼을 누르면 선택한 사업장의 현재 자료가 포함된 엑셀 파일을 내려받습니다. 현황 화면의 엑셀 버튼과 동일한 형식입니다.

2
업로드양식 시트 수정

다운로드한 파일의 업로드양식 탭에서 내용을 수정합니다. 작업 대상은 해당 열에 O를 입력하고, 해당하지 않으면 빈칸으로 둡니다.

3
수정한 파일 선택 후 검증

같은 엑셀 파일을 선택하면 필수값, 사업장 불일치, 사번 중복, 작업 대상 입력값 오류를 먼저 확인합니다.

4
검증 완료 후 반영

선택한 사업장의 기존 현황을 백업한 뒤 업로드 자료로 교체합니다. 다른 사업장 자료는 변경하지 않습니다.
